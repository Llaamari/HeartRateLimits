# Heart Rate Limits

A simple Android application that calculates heart rate limits for aerobic training based on the user's age.

This project was developed as part of a school course.

## Features

- Enter your age.
- Calculate estimated maximum heart rate.
- Calculate lower (65%) and upper (85%) heart rate limits.
- Automatically update results when the age changes.
- Display results with two decimal places.
- Use string resources for UI text.
